# Changelog

All notable changes to FlappyPy are documented here.

## [0.3.0] - 2026-09-10

### Added

- Settings for sound, music, mute, independent audio volumes, difficulty, practice mode, tutorial mode, skins, backgrounds, weather, and reduced motion.
- Countdown start sequence, extended difficulty scaling, pipe patterns, combos, near-miss bonuses, and power-ups.
- Day/night cycle, rain and fog effects, game-over celebration, and hidden `FLAPPY` easter egg.
- GitHub Pages deployment and automated repository checks.

### Fixed

- Pause now prevents simulation updates.
- Final-frame achievements are recorded before game over.
- OG Pilot requires active OG gameplay.
- Achievement persistence and visual unlock styling are reliable.

## [0.2.0] - 2026-09-09

### Added

- Achievement system, game-over score summary, responsive touch controls, and audio settings.

## [0.1.0] - 2026-09-08

### Added

- Initial playable FlappyPy browser game.
