## 🎮 About

**FlappyPy** is my take on the classic Flappy Bird-style gameplay, rebuilt as a modern browser experience.

Simple controls.  
Increasing difficulty.  
One goal:

**Beat your high score. 🐦**

---

## ✨ Features

- 🐦 Flappy Bird-style gameplay
- ⚡ Dynamic difficulty that increases as you score
- 🏆 Persistent high score
- 🎖️ Achievement system
- 🔊 Web Audio sound effects
- ⏸️ Pause / resume
- 🌆 Futuristic city environment
- 🚗 Animated flying cars
- 🎨 Modern responsive UI
- 🕹️ OG Mode
- 💾 Local storage for scores & achievements
- 📱 Responsive design

---

## 🕹️ Controls

| Action | Control |
|---|---|
| Flap | `Space` / Click |
| Pause | `P` |
| Resume | `P` |
| Restart | Click / Space |
