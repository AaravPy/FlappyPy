# FlappyPy media

The live game is intentionally dependency-free, so repository media is kept separate from the runtime.

## Capture targets

For a release-quality README update, capture these files from the live demo:

- `desktop.png`: 1440x900 browser view showing the game and achievements.
- `mobile.png`: 390x844 browser view showing the responsive game frame and touch layout.
- `gameplay.gif`: 4-8 seconds showing countdown, flap input, a pipe pass, and a power-up.

The current SVG previews are lightweight stand-ins for documentation layout and do not claim to be gameplay captures. Replace them with the files above when a browser capture environment is available.
